# 🩸 BloodLife Website

**BloodLife** is an online blood donation platform designed to bridge the gap between blood donors and recipients. This website allows users to easily register as donors, while those in need can quickly search for available blood donors in their vicinity during emergencies.

---

## 🚀 Features

- **User Registration:** Seamless sign-up process for new blood donors.
- **Blood Search:** Quick search functionality to filter donors by blood group and location.
- **Responsive Design:** Optimized for a smooth user experience across mobile, tablet, and desktop screens.
- **Contact Us:** A dedicated section for users to reach out to the administrator for support or queries.

---

## 🛠️ Tech Stack

This project is built using the following technologies:

- **HTML5:** Used for structuring the web pages.
- **CSS3:** Used for styling, layout, and making the design responsive.
- **JavaScript:** Used to add interactivity and handle dynamic functionality.
